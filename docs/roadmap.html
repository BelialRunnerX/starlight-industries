Proposed program sequence

Flight roadmap.

Four stages from a theoretical model to a first prototype flight. Dates are planning targets, not commitments.

Foundation

Theoretical validation

Define what the proposed field must do. Establish repeatable calculations and clear controls before selecting a design.

Bench phase

Instrumented demonstrator

Test for the predicted effect and rule out ordinary sources of the same signal. Proceed only if the result is reproducible.

Qualification

Prototype ground campaign

Integrate the vehicle, verify monitoring and abort systems, and complete ground testing before a flight decision.

2035 / Hypothetical first launch target

Starship Andromeda

First test launch of the Andromeda prototype vehicle, contingent on demonstrated performance, flight readiness, and applicable approvals.
