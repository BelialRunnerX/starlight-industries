# Starlight Industries

A dependency-free GitHub Pages project: company overview, a hypothetical 2035
first test launch of the Starship Andromeda prototype, and a dimensionless
Gaussian-kernel toy field explorer. No external assets, backend, analytics, or
research data.

Open docs/index.html locally to preview. On GitHub, once ready to publish,
choose Settings → Pages → Deploy from a branch → main and /docs.
Publishing may expose the site even when the source repository is private.
No custom domain is configured; confirm the deployment first and configure
the domain separately when ready.
